### Issues

**[HIGH] audience_personas.md not loaded**
- Problem: The skill loads `brand_kit.md` and `game_facts.md` but never loads `audience_personas.md`. The personas (Alex, Morgan, Jordan) are core to INWIGO's strategy but invisible here.
- Impact: Every post is written for a generic "VR gamer" rather than a specific, calibrated audience. The content_batch_agent already tags each post with target persona — the skill should too.
- Fix: Add `@context/audience_personas.md` and instruct Claude to label which persona each post targets.

**[HIGH] Twitter character limit is wrong**
- Problem: "max 240 characters" — Twitter/X's actual limit is 280 characters.
- Impact: Content is arbitrarily constrained 40 characters shorter than it needs to be.
- Fix: Change to 280 characters.

**[HIGH] No $ARGUMENTS input handling**
- Problem: `$ARGUMENTS` is passed through with no guidance on what valid inputs look like or what to do with edge cases (no input, single platform requested, vague topic).
- Impact: Inconsistent output quality depending on how the user phrases their request.
- Fix: Add an input guide section with examples and fallback behavior.

**[MEDIUM] Instagram hashtag advice is outdated**
- Problem: "30 tags, grouped by theme" — Instagram's algorithm currently performs better with 5-10 targeted hashtags in the caption. The 30-tag block is a 2019-era strategy and can suppress reach.
- Impact: Hashtag advice actively hurts Instagram performance.
- Fix: Recommend 5-10 focused caption hashtags; offer an extended block for use in comments as an optional strategy.

**[MEDIUM] No posting time/day recommendation**
- Problem: The batch agent outputs "Best day" recommendations per post; the skill doesn't. This is useful metadata a solo marketer needs.
- Impact: User has to look up optimal times separately for every post.
- Fix: Add "Best posting time" field per platform.

**[LOW] TikTok voiceover is unconditionally templated**
- Problem: "VOICEOVER SCRIPT (if applicable)" appears in every output even when clearly not needed (e.g., text-only format).
- Impact: Minor noise in outputs.
- Fix: Explicitly state when VO applies and when to omit it.
