### Issues

**[HIGH] Template placeholders will appear literally in output**
- Problem: Templates contain `[Your email]`, `[Press kit URL]`, `[platform]`, `[Name]` etc. as literal template variables. Claude will reproduce these as `[Your email]` in the output rather than generating useful placeholders.
- Impact: User receives an email draft with bracketed placeholders that look exactly like Claude was supposed to fill in — confusing and requires extra cleanup.
- Fix: Instruct Claude to generate realistic placeholder VALUES (e.g., `press@inwigo.com`, `inwigo.com/press-kit`) clearly marked with a note like "*customize before sending*" rather than leaving raw template variables.

**[HIGH] No handling for named vs. unnamed recipient**
- Problem: The creator outreach template says "specific reference to their recent content" but gives no guidance when the user doesn't provide a creator name. If someone says "write a pitch for a VR horror YouTuber" with no name, Claude will generate `[specific reference]` placeholders.
- Impact: Outputs are either under-personalized or filled with obvious placeholders.
- Fix: Add two modes: (1) Named recipient → personalize fully, invent specific references; (2) Unnamed/template mode → write a strong reusable template with clearly labeled [PERSONALIZE: reason] hooks.

**[MEDIUM] Partnership section has no template**
- Problem: "Gaming Media / Publication Partnership" section lists 6 bullet points of what to include but provides no actual email template — unlike the press and creator sections which both have full templates.
- Impact: Partnership outreach output will be less structured and more variable than other email types.
- Fix: Add a partnership email template with the same format as the other types.

**[MEDIUM] Follow-up section is very thin**
- Problem: "3-4 sentences max" is good guidance, but there's no template — just a description. The follow-up also says "reference the original pitch" which the user may not have in context.
- Impact: Follow-up emails may be inconsistent in quality or unnecessarily long.
- Fix: Add a brief follow-up template that works standalone (doesn't require the original pitch in context).

**[LOW] No timing guidance**
- Problem: When should these emails be sent? Journalists have publication cycles; creators have upload schedules. Tuesday-Thursday mornings tend to perform better for B2B outreach.
- Impact: Minor — most marketers know this, but it's a quick win to include.
- Fix: Add one line on send timing per type.

**[LOW] Subject line examples are parenthetical**
- Problem: The press template shows `e.g., "VR's answer to Lethal Company launches [date]"` as an example. This is good, but the example itself has a placeholder `[date]` which Claude may reproduce literally.
- Impact: Minor — may result in subject line "VR's answer to Lethal Company launches [date]" literally.
- Fix: Use an example with actual representative content.

- Word limits are enforced per type — this is crucial for outreach emails and often missed
- Quality checklist at the end is comprehensive and catches the most common failure modes
- "Reads like a person wrote it, not a PR department" is exactly the right bar to set
- Tone reminder ("Don't: Generic templates, overselling, jargon") is specific and useful
