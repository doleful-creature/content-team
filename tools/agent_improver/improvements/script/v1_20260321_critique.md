### Issues

**[HIGH] audience_personas.md not loaded**
- Problem: The skill loads `brand_kit.md` and `game_facts.md` but not `audience_personas.md`. A TikTok hook targeting Morgan (horror gaming fan, 18-28) is fundamentally different from one targeting Alex (VR hardware enthusiast, 25-34).
- Impact: Scripts are calibrated to INWIGO's brand voice but not to the specific viewer being targeted, reducing hook effectiveness.
- Fix: Add `@context/audience_personas.md` and instruct Claude to specify which persona the script is written for and how that shapes the hook.

**[HIGH] YouTube Short is substantially under-specified**
- Problem: The YouTube Short section says "Same structure as TikTok, but:" and lists only 3 differences. YouTube Shorts has meaningfully different audience behavior, discovery mechanics, and engagement patterns than TikTok. A one-line delta is insufficient.
- Impact: YouTube Short scripts will essentially be TikTok scripts with "Subscribe" swapped for "Follow."
- Fix: Give YouTube Shorts its own full template. Key differences to address: slightly older audience, subscribe+bell CTA, comment engagement emphasis, search-discoverable titles, slightly longer acceptable setup.

**[MEDIUM] Launch trailer timestamps don't scale to requested duration**
- Problem: The template specifies timestamps `[0:10]`, `[0:18]`, `[0:25]`, `[0:32]` as fixed. These assume a ~60-second trailer, but the template says "30-90 seconds." A 30s trailer needs entirely different pacing.
- Impact: A requested 30s trailer gets timestamps designed for a 60s trailer.
- Fix: Instruct Claude to scale all timestamps proportionally to the requested target duration. Include example pacing for 30s, 60s, and 90s variants.

**[MEDIUM] Devlog section count is rigid**
- Problem: The devlog template has exactly SECTION 1, SECTION 2, SECTION 3 hardcoded. Some devlogs need 2 sections; longer ones might need 5.
- Impact: Every devlog output has exactly 3 sections regardless of content scope.
- Fix: Change to "SECTION [N]" with a range recommendation: "2-3 sections for updates under 3 minutes; 3-5 sections for full devlogs up to 5 minutes."

**[MEDIUM] No VO guidance for INWIGO's aesthetic**
- Problem: "VOICEOVER SCRIPT (if applicable)" appears with no guidance on when VO is appropriate for INWIGO content. Horror carnival aesthetic can go either way — atmospheric silence vs. playful narration are both valid.
- Impact: Claude makes an arbitrary VO decision without brand guidance.
- Fix: Add guidance: "For TikTok/Shorts: text overlays often outperform VO for VR content (viewer reaction is the audio). For trailers: VO can work for atmospheric narration but INWIGO's style leans toward music-driven cuts with text cards. For devlogs: natural dev narration always preferred over scripted VO."

**[LOW] No script quality check**
- Problem: The skill has no equivalent of the "Brand Voice Check" that social.md has. Scripts can drift off-brand too.
- Impact: Scripts may not hit the playfully-spooky, chaotically-charming tone.
- Fix: Add a "Script Quality Check" section similar to social.md's brand voice checklist.
