### Issues

**[HIGH] System prompt is too generic**
- Problem: "You are a skilled marketing copywriter and content strategist for an indie VR game" sets a very low bar. The campaign_architect.py has a more opinionated system prompt ("You prioritize ruthlessly and are specific — no generic advice"). The batch agent's system prompt doesn't set a INWIGO-specific quality standard.
- Impact: Outputs pass the brand voice check at the prompt level rather than being enforced at the system level. Increases chance of generic, un-INWIGO content.
- Fix: Strengthen to enforce INWIGO's specific tone, comp positioning, and quality bar at the system level.

**[HIGH] No --dry-run flag**
- Problem: Every run saves to `outputs/batches/`. There's no way to preview output without saving, test the prompt on a new theme, or pipe output to stdout for inspection.
- Impact: Accumulates output files even during testing/development.
- Fix: Add `--dry-run` flag that streams to stdout only, no file save. Also add `--output-dir` for custom output location.

**[MEDIUM] Blog section produces only an outline, not an intro**
- Problem: The blog section is titled "Blog Post Outline (1 outline)" and produces section titles with bullet points. For a "full week of content" batch, this is the least useful deliverable — an outline without the intro paragraph requires another LLM call to actually produce the content.
- Impact: The blog section is placeholder-level output compared to every other section which is publication-ready.
- Fix: Change to "Blog Post Outline + Opening" — require a full introduction paragraph (first 2-3 sentences of the actual post) plus the section outline with actual key points, not just section titles.

**[MEDIUM] No Reddit post in the batch**
- Problem: The batch generates Twitter, Instagram, TikTok, Discord, and Blog — but no Reddit post. The /community and /longform skills both address Reddit. For a solo marketer doing a full week of content, Reddit is a relevant distribution channel.
- Impact: The "full week" batch is incomplete for teams that use Reddit.
- Fix: Add optional Reddit post to the batch output, or add it as a `--focus` option.

**[MEDIUM] Filename truncation cuts mid-word**
- Problem: `args.theme.replace(" ", "_")[:40]` truncates at exactly 40 characters regardless of word boundaries. "Halloween_countdown_week_2_character_rev" is harder to read than "Halloween_countdown_week_2_character".
- Impact: Minor — filenames can be ugly/truncated mid-word.
- Fix: Implement word-boundary truncation: split by `_`, join words until the string would exceed 40 chars.

**[LOW] Context load failure is logged but doesn't abort**
- Problem: If all three context files are missing (common when first setting up the tool in a new project), the agent continues with `[context/brand_kit.md not found...]` placeholders in the prompt. The output will be generic and useless.
- Impact: New users get low-quality output with no clear warning that context is required.
- Fix: Add a `--allow-missing-context` flag. Without it, abort if any critical context file is missing, with a clear setup message.

**[LOW] `--focus community` bundles Discord and Reddit**
- Problem: `--focus community` generates Discord content. There's no way to generate Reddit-only or Discord-only content.
- Impact: Minor — most users want both, but the bundling isn't obvious from the CLI help.
- Fix: Clarify in help text that "community" generates both Discord and Reddit. Optionally split into `--focus discord` and `--focus reddit`.
