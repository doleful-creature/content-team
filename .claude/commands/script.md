### FORMAT: YOUTUBE SHORT (under 60 seconds)

Similar to TikTok but YouTube Shorts audience skews slightly older. More room for setup is acceptable.

Same structure as TikTok, but:
- Subscribe + bell notification CTA instead of Follow
- Can front-load slightly more context (3-5s setup)
- Comment engagement prompt at end ("drop a 💀 if you'd survive this")

### VR-Specific Capture Notes

Include these reminders with all scripts involving VR gameplay:

- **Mixed Reality capture** (headset + real world) performs extremely well for first-person VR content — mention if relevant
- **Screen capture only** (just the headset view) looks best with good framing — note any camera angle recommendations
- **Third-person perspective** is rare in VR but worth capturing if possible for social content
- VR gameplay needs audio of player reactions — mic the player, not just the game audio
